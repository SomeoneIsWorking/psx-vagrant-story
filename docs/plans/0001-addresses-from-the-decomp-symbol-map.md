# 0001 — Addresses from the decomp symbol map

Goal: the port reads every guest address from `external/rood-reverse` instead of hand-written headers.

## Sources
- `config/<image>/symbol_addrs.txt` (upstream, read by splat) and `config/<image>/symbol_addrs_findings.txt` (names this
  port found, not read by splat until upstream's source is renamed to match), images `SLUS_010.40`, `BATTLE.PRG`,
  `INITBTL.PRG`, `TITLE.PRG`.
- Upstream names functions and globals in source without a map entry; their addresses come from the decomp.dev report
  or a linker map of the build. Each one the port uses is copied into the findings file under upstream's name.

## Generator
One psxport tool reads the splat symbol files of the images a title names and writes a header under `build/`
(`namespace <title>::guest::<image> { inline constexpr std::uint32_t <name> = 0x...; }`), regenerated by the title's
CMake when a symbol file changes. A name present in both upstream's map and the findings file is a fatal error.

## Headers it replaces, in order
1. `game/cd/cd_facts.h` (addresses only; the slot layout and states stay until upstream's `vs_CdQueueSlot` and `Disk`
   types are mirrored)
2. `game/boot/resident_facts.h`, `game/boot/game_heap.h`, `game/frame/vsync_facts.h`, `game/input/pad_facts.h`
3. `game/render/title_splash_facts.h`, `game/save/title_memcard_facts.h`, `game/save/title_save_facts.h`,
   `game/title/title_exec_facts.h`
4. `game/frame/battle_draw_facts.h`, `game/frame/location_warp.h`, `game/render/battle_projection_facts.h`,
   `game/render/battle_cull.h`, the addresses in `game/render/battle_sky.cpp` and `battle_rain.cpp`

Each step renames the port's uses to upstream's names (`docs/our-names.md` in the decomp lists the differences).
